## ¿Qué hace este proyecto?

Este proyecto muestra una infraestructura DevOps funcionando en la nube usando:

- Docker para contenedores
- GitHub Actions para CI/CD
- Google Cloud Platform (GCP)


## Cómo probarlo en tu computadora

1. Instala Docker Desktop
2. Abre una terminal en esta carpeta
3. Ejecuta: `docker build -t mi-app .`
4. Ejecuta: `docker run -d -p 80:80 --name mi-app mi-app`
5. Abre tu navegador en `http://localhost`
